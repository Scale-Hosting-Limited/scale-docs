New to hosting? The jargon can be the hardest part. Here are the terms you'll see
throughout this Help Center, explained simply, with pointers to where each is covered
in depth.

## Accounts and billing

- **Service** — anything you host with us: a game server, website, mailbox, or bot.
  See *Managing your services*.
- **Invoice** — the bill for a service, showing what you're paying and when. See
  *Understanding your invoice*.
- **Billing cycle** — how often a service renews (monthly, quarterly, yearly).
- **Provisioning** — us setting up your service automatically after you order. See
  *What happens after you order*.
- **Suspension** — a service paused (usually for an unpaid invoice); not yet deleted.
  See *Failed payments and overdue services*.

## Domains and DNS

- **Domain** — your web address, like `yourname.com`. See *Registering a new domain*.
- **DNS** — the system that turns a domain into the right destination. See *Managing
  DNS records*.
- **Nameservers** — which provider answers for your domain and holds its DNS. See
  *Nameservers explained*.
- **A record / CNAME** — DNS records pointing a name at an IP address or another
  hostname.
- **MX / SPF / DKIM / DMARC** — DNS records that make email work and deliver. See
  *Setting up email DNS records*.
- **Subdomain** — a prefix like `play.yourname.com`. See *Setting up a subdomain*.
- **Propagation** — the delay while a DNS change spreads worldwide (minutes to
  ~48 hours).

## Web hosting

- **Web root / `public_html`** — the folder your website is served from. See *Using
  the file manager*.
- **FTP / SFTP** — ways to upload files; SFTP is the secure one. See *Connecting with
  FTP and SFTP*.
- **SSL / HTTPS** — the padlock; encrypts your site. See *Enabling SSL / HTTPS*.
- **Database / MySQL** — where apps like WordPress store content. See *Managing MySQL
  databases*.
- **PHP** — the language most web apps run on; it has versions. See *Choosing a PHP
  version*.
- **Cron job** — a task that runs on a schedule. See *Setting up cron jobs*.

## Game servers

- **Panel / console** — where you run and watch your server. See *Using the game
  panel console*.
- **RAM / CPU / disk** — your server's resources; running out causes lag or crashes.
  See *Out of memory and resource limits*.
- **Mod / plugin** — add-ons that change or extend a game. See *Installing mods and
  workshop content*.
- **Backup / restore** — a saved snapshot you can roll back to. See *Backing up and
  restoring*.
- **Whitelist** — an allow-list so only approved players can join.

## Email

- **Mailbox** — a real inbox with storage and a login. See *Creating a mailbox*.
- **Alias / forwarder** — extra addresses that feed a mailbox or send mail elsewhere.
  See *Aliases, forwarders, and catch-all*.
- **IMAP / POP / SMTP** — protocols for receiving (IMAP/POP) and sending (SMTP) mail.
  See *Connecting your email client*.

## Security

- **2FA** — a second login step beyond your password. See *Enabling two-factor
  authentication*.
- **Passkey** — a phishing-resistant sign-in using your device. See *Passkeys and
  social login*.
- **Phishing** — fake messages trying to steal your login. See *Recognising phishing
  and scams*.

## Still unsure?

If a term isn't here or you'd like it explained, ask — see *Getting help when you
need it*. There's no such thing as a silly question when you're getting started.
