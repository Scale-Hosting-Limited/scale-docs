Not sure which plan to pick? Here is how to think about it.

## Match the plan to what you are hosting

- **Game servers (e.g. Minecraft):** the number of players and the mods/plugins
  you run drive how much RAM you need. A vanilla server for a few friends needs
  little; a heavily-modded pack for a big community needs much more.
- **Web hosting:** most sites start comfortably on an entry plan. Move up when you
  need more storage, more traffic, or more sites.
- **Email hosting:** choose based on the number of mailboxes and storage per
  mailbox.

## You can change later

Plans can be upgraded (and usually downgraded) from the panel — you are not locked
in. If you are unsure, start smaller and scale up when you need to; upgrades are
prorated so you only pay the difference.

## Still unsure?

Open a ticket with a short description of what you want to run and roughly how
many players/visitors/mailboxes you expect, and we will recommend a plan.
