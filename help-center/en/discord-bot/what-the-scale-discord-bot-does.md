The Scale Discord bot brings your game server into your Discord community — check
status, control the server, and get alerts without leaving Discord. This is the
quick tour of what it can do and where to start.

> **Not to be confused with Discord Bot Hosting.** This is *our* bot that you add to
> manage your Scale servers. If you want to host **your own** bot 24/7, see the
> *Discord Bot Hosting* section instead.

## What it's for

- **See server status** at a glance — online/offline, player count, performance.
- **Control your server** — start, stop, and restart from Discord (with the right
  permissions).
- **Get notified** — alerts when the server goes down, comes back, or crosses a
  resource threshold.
- **Keep your community informed** — status updates where your players already hang
  out.

It's the easiest way to keep an eye on a server day to day, especially from your
phone.

## Getting started

1. **Add the bot** to your Discord server — see *Adding the bot to your server*.
2. **Link your game server** so the bot knows which server to manage — see *Linking
   your game server*.
3. **Set permissions** so only trusted roles can control the server — see *Setting up
   permissions and roles*.
4. **Turn on notifications** for status and alerts — see *Configuring status
   notifications*.

Do those four and you're fully set up.

## What you'll use most

- **Status commands** to check the server (see *Viewing stats and console in
  Discord*).
- **Power commands** to restart when needed (see *Controlling your server from
  Discord*).
- **Alerts** so you hear about problems before your players do (see *Alert thresholds
  and notifications*).
- The full list of commands is in *Bot commands reference*.

## Permissions and safety

Because the bot can control your server, **who can use which commands matters**. Set
it up so:

- Only **admins/mods** can start/stop/restart.
- **Everyone** can safely check status (if you want).

See *Setting up permissions and roles* — get this right before giving the bot to a
big community.

## Requirements

- A **game server** with us that supports the bot.
- A **Discord server** you manage (you'll need permission to add bots).
- Your server **linked** to the bot via your panel.
