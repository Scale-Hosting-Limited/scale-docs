Linking tells the bot which server to report on for a given Discord.

## Pair with a code

1. In the panel, open your service's **Discord** tab and generate a **pairing
   code**. Codes are short-lived and single-use.
2. In your Discord, run the bot's pairing command and enter the code.
3. The bot confirms the link. It can now show that server's status and respond to
   the commands you have enabled.

## What the bot can and cannot do

- It shows status (online/offline, player count) and can run the actions you
  approve.
- It never exposes your account details or billing to your Discord — it only knows
  the server label.
- Power and console actions still go through the panel's own permissions, so the
  bot is never a weaker way into your server.

## Unlinking

Remove the link from the **Discord** tab at any time; the bot immediately loses
access to that server.
